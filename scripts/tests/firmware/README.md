# 固件主机回归测试

在项目根目录运行：

```powershell
./scripts/tests/firmware/run.ps1
```

脚本使用本机已有的 Clang 和 Windows C 运行库，不下载依赖。编译输出位于 `build/host-tests/`，以 `-Wall -Wextra -Werror` 编译并执行六组测试：

- 前视点：直线、偏离路径、切点、折线、重复路径点、单点和无效输入。
- 使用仓库中的真实 CMSIS-DSP 实现重新运行数学测试，验证单位向量、直接旋转和旋转矩阵的弧度契约。
- HAGL 缩放：将大画布完整绘制的结果与屏幕/用户 clip 裁剪的结果逐像素比较，同时检查源 pitch 和缓冲区哨兵。
- PWM：模拟拿锁前另一个任务改频，验证共享 slice、关断恢复、相同频率下 duty 更新，以及错误/锁超时后的状态保持。
- ADC：模拟 FIFO 的单次转换入队和 DMA 重启，验证温度通道映射及多次 PG/温度读取后的电压通道顺序。
- SPI：模拟 DMA 中断先于最后一帧移位完成、BSY 卡住、DMA 无完成信号及超时后再次传输；检查调度器状态和引脚分配。

测试直接编译生产代码。数学和 HAGL 使用真实实现；PWM/ADC/SPI 只替换 SDK 和 RTOS 的硬件接口，用于验证软件状态与调用顺序。测试不替代 RP2350 上的真实中断、双核并发和电气时序验证。上板前按 `docs/hardware.md` 调整 LCD 接线。
